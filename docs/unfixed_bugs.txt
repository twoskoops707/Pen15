FIXED THIS SESSION (2026-08-11):
- Theory 17 (recommended in bugs journal): nfc_emulate now accepts optional
  "atqa" (16-bit hex) and "sak" (8-bit hex) JSON fields. Defaults to
  0x4400/0x00 (NTAG-compatible) when absent. Enables perfect clone of a
  detected card's ATQA/SAK. FILE: fap/pen15_controller/pen15_controller.c
- FapProtocol.nfcDetect callback now returns (type, uid, atqa, sak).
  FapProtocol.nfcEmulate accepts optional atqa/sak parameters and forwards
  them to the FAP. FILE: FapProtocol.kt
- NFCActivity.SavedTag now persists atqa/sak per tag, so re-emulating a
  saved card uses that card's exact ATQA/SAK response. Detection callback
  captures the two new fields. FILE: NFCActivity.kt
- ERR-43: Deleted FlipperDevice.kt and Esp32Device.kt — both were dead code
  (no other .kt file referenced them). FlipperDevice used CLI-prompt
  protocol incompatible with FAP JSON mode. Esp32Device duplicated
  ESP32SerialManager, which is the wired implementation.
