        protocol index as hex (e.g. "04" for ISO14443-3A) rather than the actual

        real card UID.
        IMPACT: Cannot clone/save specific NFC tags by UID.
        FIX NEEDED: Use nfc_device_alloc() + nfc_worker to do a full read that
        returns actual UID bytes from the ATQA/SAK/UID response.
